# Guía Django

Guía interactiva para aprender los fundamentos de Django desde cero. Presenta los conceptos principales del framework mediante explicaciones, ejemplos de código y una navegación paso a paso.

## Descripción

Este proyecto reúne una serie de explicaciones prácticas para comprender cómo funciona Django y cómo se estructura una aplicación web utilizando Python.

El contenido está organizado en diferentes secciones que permiten avanzar progresivamente por los conceptos fundamentales del framework.

## Contenido

La guía aborda los siguientes temas:

1. ¿Qué es Django?
2. Instalación y entorno virtual.
3. Creación de un proyecto.
4. Modelos.
5. Vistas.
6. URLs.
7. Templates.
8. Panel de administración.
9. Flujo completo de una petición.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Características

- Navegación interactiva entre lecciones.
- Barra de progreso para visualizar el avance.
- Ejemplos de código.
- Explicaciones paso a paso.
- Diseño adaptable a diferentes dispositivos.
- Modo claro y oscuro según las preferencias del sistema.
